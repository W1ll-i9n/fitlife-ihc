# FITLIFE — Atividade Acadêmica de IHC

Este é um protótipo de uma interface web desenvolvido como atividade acadêmica da disciplina de Interface Humano-Computador (IHC).

## Sobre o projeto

O FITLIFE é um protótipo de uma área do aluno de uma academia, desenvolvido com foco em conceitos de IHC, usabilidade e organização da interface.

O projeto apresenta as seguintes telas:

- Login
- Meu Cadastro
- Meus Treinos
- Agendar Avaliação Física
- Meu Perfil

## Objetivo

Aplicar conceitos de Interface Humano-Computador na criação de uma interface simples, organizada e de fácil utilização.

## Tecnologias

- HTML5
- CSS3
- JavaScript
